# Практична робота 9.1: Робота з SharedPreferences у Flutter

## Варіант 1: Менеджер налаштувань користувача

### Опис проєкту
Додаток для управління користувацькими налаштуваннями на Flutter із збереженням даних у форматі key-value за допомогою пакета `shared_preferences`.

### Функціональні можливості:
- **Singleton Сервіс (`PreferencesManager`)**: єдина точка доступу до збереження та зчитування даних.
- **Профіль користувача**: ім'я, email, вік, дата реєстрації.
- **Налаштування UI**: зміна теми (light/dark/system), розміру шрифту, мови, компактного режиму з реальним оновленням інтерфейсу.
- **Сповіщення**: керування switch-перемикачами та частотою нагадувань.
- **Категорії**: додавання/видалення тегів (Chips).
- **Auto-save & Feedback**: автозбереження кожної зміни з візуальним підтвердженням через `SnackBar`.
- **Експорт у JSON**: перегляд поточних налаштувань у форматі JSON.
- **Скидання налаштувань**: повне очищення даних до типових значень.
